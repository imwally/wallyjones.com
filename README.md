# wallyjones.com

My little homepage running on [OpenBSD](https://www.openbsd.org) using
[httpd](https://man.openbsd.org/httpd.8) and
[acme-client](https://man.openbsd.org/acme-client.1). 

Hosted on [DigitalOcean](https://www.digitalocean.com/).

[Read](https://nil.wallyjones.com/run-openbsd-on-digitalocean-for-4month/)
about how you can do the same for $4/mo.
